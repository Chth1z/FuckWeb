    安全与协议策略

    其余流量（防泄漏）所有非中国大陆地址及 Claude / Stripe / GrowthBook 关联域名一律强制进台湾家宽隧道，严禁直连泄漏。
    强制进隧道（已锁定）
    QUIC（UDP 443）内核层毫秒级拦截 UDP 443，强制浏览器与应用回退至多流 TCP，突破单连接 10 Mbit/s 限速帽。
    强制回退 TCP（已锁定）
    广告域名拦截在 DNS 层直接返回空地址。

    隧道与 Claude 防封锁笼

    隧道总控全局启用透明代理与 SmartDNS 域名锚定（@tunnel4_dns），禁止关闭以防真实 IP 暴露。
    始终开启（已锁定）
    故障保护（Fail-Closed 硬件锁）braid_guard 独立内核表：即使隧道进程异常，海外流量也绝对禁止回退直连，确保 Claude 0 大陆 IP 泄漏。
    严禁放行（已锁定）

    中继 点击切换；圆点颜色表示延迟
